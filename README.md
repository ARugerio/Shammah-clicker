# SHAMMAH Clicker Studio 🖨️

Generador paramétrico 3D para la creación de clickers mecánicos (interruptores Cherry MX), optimizado para impresión FDM multicolor con sistema AMS en Bambu Lab P2S. 

Esta herramienta permite transformar imágenes, archivos SVG, iconos y texto directamente en modelos `.3mf` con cuerpos separados y listos para laminar.

**Enlaces de Acceso:**
* 🏪 **Mostrador Principal:** [SHAMMAH CREA 3D](https://arugerio.github.io/Shammah3d/)
* ⚙️ **Generador 3D:** [Clicker Studio](https://arugerio.github.io/Shammah-clicker/)

**Créditos y Reconocimientos**
Este software independiente es una adaptación del proyecto original *Clicker Generator* desarrollado por [Vostok Labs](https://github.com/vostoklabs/Clicker-Generator). Todos los créditos del motor geométrico base y la arquitectura WebAssembly pertenecen a sus autores originales.
